Pagina Web HTML

Instrucciones:

Leer las instrucciones de cada caso de uso y generar una página web en HTML para cada caso.

Se debe de entregar un solo repositorio con las 3 páginas.

Nombrarlas de las siguiente forma:

registro.html
sesion.html
perfil.html

Entregable:

Repositorio con las 3 páginas solicitadas.

Página de Registro
Descripción: Esta página tiene un formulario para que los usuarios puedan registrarse en el sitio web proporcionando información como su nombre, correo electrónico, contraseña y otros detalles opcionales. Una vez que el usuario completa el formulario, al enviarlo se guarda la información en el sistema.

Etiquetas mínimas a utilizar:

Estructura básica:

<html>, <head>, <meta>, <title>, <body>
Encabezado y pie de página:

<header>, <footer>
Contenido de la página:

<h1>, <h2>, <p>
Formulario y elementos interactivos:

<form>, <label>, <input>, <textarea>, <button>, <select>, <option>
...................................................................................................................
2. Página de Inicio de Sesión
Descripción: En esta página, los usuarios pueden acceder a su cuenta proporcionado su correo electrónico y contraseña. Si los datos son correctos, el sistema permitirá que el usuario se autentique. También, habrá un enlace que lleva a los usuarios a la página de registro si no tienen cuenta.

Etiquetas mínimas a utilizar:

Estructura básica:

<html>, <head>, <meta>, <title>, <body>
Encabezado y pie de página:

<header>, <footer>
Contenido de la página:

<h1>, <h2>, <p>
Formulario de inicio de sesión:

<form>, <label>, <input>, <button>
...................................................................................................................
3. Página de Perfil de Usuario
Descripción: Esta página muestra la información del perfil del usuario, como su nombre, correo electrónico, dirección y país. Además, permite al usuario actualizar su información a través de un formulario de edición. El perfil puede incluir tanto datos de solo lectura como campos editables.

Etiquetas mínimas a utilizar:

Estructura básica:

<html>, <head>, <meta>, <title>, <body>
Encabezado y pie de página:

<header>, <footer>
Contenido de la página:

<h1>, <h2>, <p>
Formulario de actualización:

<form>, <label>, <input>, <textarea>, <button>, <select>, <option>
